# CLAUDE.md

This file provides guidance to Claude Code when working with this plugin.

## Plugin Description

**boards** is a multi-agent board review plugin that assembles panels of specialized AI agents to analyze topics from multiple expert perspectives. Each board runs 6 independent agents in parallel, then a critic reviews all responses, followed by a synthesis.

## Commands

| Command | Description |
|---------|-------------|
| `/board-meeting <topic>` | AI Board Meeting — 7 C-suite agents (CEO, CFO, CMO, COO, CTO, Research, Critic) analyze any business decision |
| `/ux-board <url\|path\|description>` | UI/UX Board Review — 7 specialists (Visual Designer, UX Strategist, IA, Accessibility, Mobile, Performance, Critic) analyze screens |
| `/boards:help` | Show available board commands |

## Architecture

### Execution Pattern (shared by both boards)

```
User provides topic/target
    |
    v
Step 1: Setup & load context/history
    |
    v
Step 2: Launch 6 independent agents IN PARALLEL (single message, 6 Agent calls)
    |
    v
Step 3: Launch Critic agent (sees all 6 responses)
    |
    v
Step 4: Generate synthesis (done by main agent, not a subagent)
    |
    v
Step 5: Format & display results
    |
    v
Step 6: Save to persistent storage
```

### State Persistence

- Board meetings: `~/.claude/board-meeting/meetings/`
- UX reviews: `~/.claude/ux-board/reviews/`

### Key Rules

- ALL 6 independent agents MUST run in parallel (single message, 6 Agent tool calls)
- The Critic MUST see all other responses before running
- Max 300 words per agent
- Agents return ONLY analysis text — no tool calls, no file reads
- Synthesis is generated by the main agent, not a subagent
- Language: match the user's language

## Chrome Integration

The `ux-board` command can use Chrome automation to navigate to URLs and take screenshots for visual analysis. Requires the Claude in Chrome extension.
